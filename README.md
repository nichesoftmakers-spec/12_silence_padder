## ■ こんな「音声の余白トラブル」、手動で修正していませんか？

- **動画編集ソフトに音声を並べたとき、先頭の無音が足りずに「あっ」という最初の1文字がプチッと途切れる（頭切れ現象）**
- **教材音声やリスニング問題、オーディオブックで、ファイルごとに前後の空白の長さがバラバラで統一感がない**
- **DAWや波形編集ソフトを立ち上げ、1本ずつ無音トラックを挿入して書き出す単純作業に毎月何時間も奪われている**
- **ゲーム開発やシステム音声で、発音レスポンスを損なわずにクリックノイズだけを防ぐ極小余白（30ms）を一括で入れたい**

音声ファイルの前後余白は、動画テロップとの同期やリスナーの聞き取りやすさを左右する極めて重要な下処理です。  
しかし、**本来クリエイティブであるはずの貴重な時間を、単純な無音の挿入と書き出し作業に奪われ続ける必要はありません。**

「SilencePadder GUI」は、そんな制作現場の地味で膨大な作業をワンクリックで解消するために開発された、完全実務特化型のポータブルソフトウェアです。

## ■ なぜ、他の方法ではなく「SilencePadder」なのか？（4つの圧倒的理由）

### 1. 動画用・教材用・ゲーム用の「ワンクリック用途別プリセット」搭載
先頭・末尾の無音ミリ秒を用途別にワンクリックで最適化：
- **動画・YouTube用**: 先頭 150ms / 末尾 300ms（頭切れ防止＆テロップ同期の黄金比）
- **教材・オーディオブック用**: 先頭 500ms / 末尾 1000ms（呼吸・思考の間合いを確保）
- **ゲーム・効果音用**: 先頭 30ms / 末尾 150ms（レスポンスを損なわずプチ音を防止）
- **カスタム指定**: 1ms〜5000msまでミリ秒単位で完全自由指定可能

### 2. 不揃いな既存無音をリセットする「クリーン・パディング」機能
元ファイルによって「先頭に0.05秒の余白がある」「末尾に1.2秒も無音がある」といったバラつきがある場合でも、「既存余白リセット」を有効にすれば、元ファイルの余白を自動検知して一度リセットした上で指定ミリ秒を付加。**すべてのファイルを1ミリ秒の狂いもなく完全等長余白に均一化**します。

### 3. プチ音を完全防止する「ゼロ交差点＆マイクロフェード」技術
無音配列を単純に連結すると、波形の途切れ目で「プチッ」というクリックノイズが発生することがあります。本ツールはゼロ交差点判定と3msの極小マイクロフェードを自動適用し、**一切のノイズを出さずに滑らかに無音へ接続**します。

### 4. 面倒な環境構築ゼロ。解凍してダブルクリックですぐ起動
Pythonのインストールや黒い画面（コマンドプロンプト）の操作は一切不要です。  
配布ZIPを解凍し、専用ランチャーをダブルクリックするだけで直感的な操作画面がスッと立ち上がります。外部通信を一切行わない完全ローカル動作のため、未公開案件や社外秘ナレーションも安全に処理できます。

## ■ 使い方（かんたん3ステップ）

1. **起動する**: フォルダ内のランチャー（`START_APP.vbs` または `run.bat`）をダブルクリックします。
2. **放り込む**: 余白を揃えたい音声ファイル（WAV, MP3, FLAC, OGG）をまとめてドラッグ＆ドロップします。
3. **ボタンを押す**: **「前後無音パディングを実行」** をクリック！
   - 処理前後の尺（秒・ミリ秒）が一覧表示されます。
   - **「📦 均一パディング済みWAV ＆ 集計レポートを一括ダウンロード（ZIP）」** を押せば、高音質24bit WAVと集計レポートCSVが一瞬で手に入ります。

## ■ 動作環境・仕様

- **対応OS**: Windows 10 / 11 (64-bit)
- **インストール**: 不要（完全スタンドアロン動作・Embedded Python同梱）
- **対応入力フォーマット**: WAV, MP3, FLAC, OGG
- **出力フォーマット**: 24-bit PCM WAV（原音のサンプリング周波数・チャンネル数を完全維持）
- **無音パディング範囲**: 先頭 0〜5000ms / 末尾 0〜5000ms（10ms単位で指定可能）
